- **Evidencia por frase:** quedó en el espacio temporal de la sesión, fuera del repositorio. Cada frase se reproduce con `family_parser.parse_family_actions`.
- **Uso permitido:** encontrar fallas y, tras la priorización, servir de prueba. **Nunca** como estándar de referencia ni como datos del piloto.

## Clases de entrada

- `LIST`: varias órdenes en una frase
- `ROUTE`: vía compartida
- `DOSE`: dosis compartida
- `SEQ`: ahora… luego / now… then
- `IFNO`: si no responde / if no response
- `REP`: repetir / repeat
- `NEG`: negación
- `CHG`: cancelar o cambiar una orden
- `TREASS`: reevaluación con tiempo
- `EXPECT`: expectativa
- `REASON`: razonamiento + acción
- `ABBR`: abreviaturas
- `COLLOQ`: lenguaje coloquial
- `DISPO`: destino / seguimiento / aviso de regreso
